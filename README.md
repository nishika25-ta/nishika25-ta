## About

I am **Valentine Agam**, a software engineer based in Miri, Sarawak, building full-stack products, enterprise workflows, and applied AI systems. My background in Cognitive Science and Computer Science shapes a product-engineering approach that connects human needs, dependable architecture, and measurable outcomes.

At **Hospital Miri**, I lead end-to-end development for digital onboarding, asset tracking, public web experiences, and hospital wayfinding initiatives. I also co-founded **Scribear**, where I translate client requirements into responsive applications, REST APIs, relational data models, and production deployments.

My engineering focus spans **software architecture**, **AI/ML**, **full-stack delivery**, and **digital transformation**. I care about accessible interfaces, maintainable systems, responsible data handling, and solutions that remove friction from real operational work.

> **Open to:** software engineering, full-stack product development, applied AI/ML, digital transformation, and meaningful open-source collaboration.

<br />

An educational security research platform that analyzes Windows Portable Executable files and explains why a sample is classified as benign or malicious.

| Dimension | Engineering Detail |
|:---|:---|
| **Stack** | Python, XGBoost, LightGBM, SHAP, Flask, pefile, scikit-learn |
| **Scale** | EMBER-compatible training pipeline for **1.1M samples** and **412 engineered security features** |
| **Performance** | GPU-ready training, single-file analysis, directory batch scanning, and CLI automation |
| **Security** | Static PE inspection across headers, sections, imports, entropy, strings, and byte histograms |
| **Impact** | Makes malware decisions interpretable through ranked SHAP contributions and exportable reports |
| **Repository** | [github.com/nishika25-ta/XAI](https://github.com/nishika25-ta/XAI) |

The project joins a web dashboard, REST endpoints, and a command-line workflow around one analysis core. It is explicitly scoped for education and research, with clear guidance that demo models use synthetic data and are not antivirus replacements.
